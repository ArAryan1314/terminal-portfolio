# Security Policy

This repository is a fork of [satnaing/terminal-portfolio](https://github.com/satnaing/terminal-portfolio).

- Vulnerabilities in the **original project**: please report them upstream, following the policy at <https://github.com/satnaing/terminal-portfolio/security>.
- Issues specific to **this fork** (CI, configuration, changes made here): open a private advisory via the **Security** tab of this repository.
